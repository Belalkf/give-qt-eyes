# Report a security problem

Use [GitHub private reporting](https://github.com/Belalkf/give-qt-eyes/security/advisories/new) for sensitive findings. Do not post passwords, keys, or private images in public issues. No response time is promised.

## Keep captures private when needed

Images can show private text even when the JSON leaves out widget text and object names. Use sample data and check images before sharing them. The helper runs inside your app's test process. Use trusted code; do not run an unknown app just to inspect its screenshot.

The comparison command reads only the files you select, up to 2 MB each. The skill installer writes to the user or project folder you choose and refuses existing files, folders, or links. A path in an image record or website does not give permission to use that path.

Installing the Python package does not install the skill or change agent settings. The tool uses no network at runtime and stores no passwords or keys.
